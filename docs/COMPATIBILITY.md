PDF export uses Chromium, contains selectable text and raster images, uses the chosen page size and supports real page numbering. There is no PDF import/editing. Print preview displays the generated PDF; opening preview is not a physical-printer test.

DOCX conversion is deliberately a subset, not a Microsoft Word layout clone. It does not support tracked changes, floating objects, multi-column sections, footnotes/endnotes, equations, embedded OLE objects, arbitrary Word fields, review import/export or exact style fidelity. A compatibility notice appears on DOCX import and before export. Source DOCX is imported into a new unsaved BeastText document; Save defaults to native format.

HTML passes DOMPurify plus style/URL filters; remote images, scripts, event attributes and embedded frames are discarded. No remote content is fetched. Export embeds raster assets as data URIs. TXT and Markdown exports show a loss notice and always write separate files. Keep the native file as the authoritative version.

Spelling: bundled US/UK English local nspell/SCOWL dictionaries, right-click suggestions and a persistent personal dictionary. Checking and corrections are provided locally across Windows and Linux rather than relying on native Windows suggestions. No grammar service or AI dependency. Other languages require a future bundled dictionary update.
